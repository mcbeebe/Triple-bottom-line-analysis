The revised plan (docs/dev-package/phase-2-plan.md) changes four things: the trade path field becomes “Trade-in offer” (P4); miles is one slider with a readout, no typed field (P5); the “Not sure” option is hidden until Phase 4 (P8); “Something else” does not repeat the value field. Every value also shows Placeholder, Source or Your number.

TBL Scorecard: Phase 2 screens (mockup)

Ten phone-width (390 px) screens for Phase 2, drawn with the real design system: the tokens and component styles are copied from src/ui/tokens.css and src/ui/components.css, and the step header, footer, option buttons, chips and buttons are produced by the real ds* renderers. The slider, checkbox rows, comma-formatted text money fields (with their error state), the "Something else" and "Add my own car" sub-forms, the Placeholder label, the note box and the 4-car message are proposed, not built yet; their styles sit in a separate block and use only existing tokens. Copy follows docs/dev-package/phase-2-plan.md (Screens section); captions say "proposed" where the plan marks copy as proposed. Car names and prices come from CATALOG in src/data.ts. This is a static picture: nothing is wired up.
